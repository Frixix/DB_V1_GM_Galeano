# 🚀 Identidad Visual & Marca — EducoKrea

¡Bienvenido a la carpeta de identidad de la plataforma **EducoKrea**!

Aquí tienes los archivos de prueba listos. Puedes **reescribir directamente el contenido del archivo SVG** o **reemplazarlo/sobrescribirlo** con tu propio archivo de diseño (`.svg`, `.png`, `.webp`).

---

## 📁 Archivos incluidos en esta carpeta:

| Archivo | Tipo | Uso Recomendado | Dimensiones Sugeridas |
| :--- | :--- | :--- | :--- |
| `logo.svg` | Vectorial horizontal | Logo completo con isotipo + texto "EducoKrea" para login, barra superior y documentos oficiales | 520 × 120 px (o proporcional) |
| `symbol.svg` | Vectorial cuadrado / Isotipo | Símbolo o monograma "EK" para favicons, app icon, badges y avatar de sistema | 128 × 128 px (o 512 × 512 px) |

---

## 💡 ¿Cómo lo reescribes o personalizas?

1. **Opción A (Reescribir el SVG directamente):**
   - Abre `logo.svg` o `symbol.svg` en este editor o en cualquier editor de código y pega el código SVG de tu diseño. ¡Se actualiza de inmediato!

2. **Opción B (Pegar una imagen PNG o SVG desde el explorador):**
   - Si tienes tu logo exportado de Illustrator, Figma, Canva o Photoshop:
     - Guárdalo con el nombre exacto `logo.svg` (o `logo.png`).
     - Al reemplazarlo en esta carpeta, el sistema ya sabrá dónde encontrarlo automáticamente.

---

> **Ruta pública en la web:**  
> Cualquier archivo aquí dentro se carga en la app directamente desde:  
> `/images/educokrea/logo.svg` y `/images/educokrea/symbol.svg`.
