# Carpeta de Imágenes Institucionales — Gimnasio Martin Galeano

En esta carpeta puedes colocar las imágenes del sistema (logos, fotos de perfil / avatares, etc.).

## 📁 Estructura recomendada:

### 1. Avatares de Perfil (`public/images/avatars/`)
Coloca aquí las fotos de los usuarios. El sistema detecta automáticamente la imagen y, si no existe o no se encuentra, muestra la letra inicial correspondiente (por ejemplo la **C** para Claudia).
- **Rectora (Claudia)**: `rectora.png` (o `claudia.png`)
- **Administrador**: `admin.png`
- **Jessica**: `jessica.png`
- **Yuri**: `yuri.png`
- **Elcy**: `elcy.png`

> **Formato recomendado**: Archivos `.png`, `.jpg`, `.jpeg` o `.svg`, preferiblemente cuadrados (ej: 256x256 px o 512x512 px).

---

### 2. Logos Institucionales (`public/images/logos/`)
Coloca aquí el escudo o logo oficial del colegio:
- **Logo Principal**: `logo.png` (o `logo.svg`)
- **Logo Reducido / Favicon**: `logo-small.png`

Si el logo no está presente, el sistema mostrará automáticamente el icono institucional de birrete académico (`ph-graduation-cap`).
